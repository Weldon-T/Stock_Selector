1. 项目概述
================================================================================

1.1 项目背景
基于A股市场，构建轻量级全自动选股工具，融合基本面与资金面因子，通过多因子
打分模型筛选优质标的。使用Tushare免费API，结果输出为CSV文件，方便个人投资
者复盘验证。

1.2 项目目标
- 实现可配置、可追溯的多因子打分选股引擎。
- 基本面因子：估值、盈利、成长、质量；资金面因子：量价、融资融券、北向资金
 （在免费权限内可用）。
- 端到端流程：数据获取、清洗、计算、排序、输出。
- 输出UTF-8 CSV文件，Windows Excel可直接打开。
- 支持简单历史回测与绩效统计（可选）。

2. 功能需求
================================================================================

2.1 股票池初始过滤
- 剔除ST、*ST、退市整理板股票。
- 剔除上市不足60个自然日的新股。
- 剔除最新交易日无交易或长期停牌（连续10日无成交）的个股。
- 仅保留沪深A股（主板、创业板、科创板，可在配置中调整）。

2.2 基本面因子
因子名称          方向      计算方式/数据来源
----------------------------------------------------------------
PE_TTM            负向       daily.pe_ttm，越低越好
PB_LF             负向       daily.pb
ROE_TTM           正向       从income/balancesheet计算或fina_indicator
净利润同比增长率   正向       最新单季度归母净利润同比(income)
营收同比增长率     正向       最新单季度营业收入同比(income)
资产负债率         负向       总负债/总资产(balancesheet)，金融行业中性处理

2.3 资金面因子
因子名称          方向      计算方式                          权限要求
----------------------------------------------------------------
量比               正向       5日均量 / 20日均量(daily计算)    无限制
融资余额变化率     正向       近5日融资余额累计变化百分比(margin)  免费可用
北向资金净流入     正向       近5日北向净买入/自由流通市值      受限，不可用时关闭
主力资金净流入(5日) 正向      moneyflow.main_net_inflow累计    需积分，不可用时关闭

若部分因子不可用，可在config.yaml中将enabled设为false，其权重按比例分配至
其他可用因子，资金面总权重默认为0.30。

2.4 打分合成
- 对每个因子计算全市场百分位排名(0~1)。
- 负向因子取 1 - rank 转为正向得分。
- 加权得分：Score = Σ(w_i × rank_i)，w_i可正可负。
- 按总分降序，取前N只股票（默认50）。

2.5 行业中性化（V1.1可选）
先在申万一级行业内排名，再汇总得分，避免板块集中。

2.6 简单回测
- 指定历史日期运行选股，持有20日计算收益率。
- 统计年化收益、夏普比率、最大回撤、胜率等。
- 结果输出到控制台或单独CSV。

2.7 数据输出与日志
- 输出格式：选股结果_YYYYMMDD.csv，UTF-8 with BOM编码，逗号分隔，含中文列名。
- 日志记录：运行状态、数据缺失、异常跳过股票代码及原因，保存在logs/run.log。
- 控制台打印Top10摘要，不做强制推送通知。

2.8 用户配置系统（config.yaml）
可修改内容：
- 股票池范围（板块、上市天数）
- 各因子启用状态与权重
- 选股数量N
- Tushare token
- 输出路径与缓存路径
- 回测开关及日期范围

3. 数据需求（Tushare免费版）
================================================================================

3.1 接口清单
接口名称        用途                    免费权限限制
----------------------------------------------------------------
stock_basic     股票基础信息(上市日期、ST)  无限制
trade_cal       交易日历                 无限制
daily           日线行情(含pe_ttm,pb)    免费可用，单次最多取一年
income          利润表(单季度)          免费可用
balancesheet    资产负债表              免费可用
margin          融资融券明细            免费可用
moneyflow       个股资金流向            需2000积分，若无则放弃
hsgt_top10      沪深港通十大成交股      免费但信息不全
hk_hold         沪深港通持股明细        需较高积分，若无则舍弃

3.2 数据填充规则
- 日频数据缺失：剔除该股票当天计算（记录日志）。
- 季报空窗期：沿用最近一次财报数据，并在输出中标注financial_period列。
- 上市不足一年导致部分成长因子缺失：赋中性值(排名0.5)。

3.3 本地缓存
采用SQLite或Parquet文件缓存历史数据，降低API调用频率。每日增量更新，启动时
自动检查缓存日期。

  fundamental:
    pe_ttm:            { weight: -0.20, enabled: true }
    pb:                { weight: -0.10, enabled: true }

    net_profit_yoy:    { weight:  0.15, enabled: true }

6. CSV输出格式
================================================================================

示例列名：
ts_code, name, industry, final_score,
pe_ttm, pe_rank, pb, pb_rank, roe_ttm, roe_rank,
net_profit_yoy, np_rank, revenue_yoy, rev_rank,
debt_ratio, debt_rank, volume_ratio, vol_rank,
margin_chg, margin_rank, financial_period

- financial_period：标明所用最新财报截止日（如20250930）。
- CSV按final_score降序排列，首列为股票代码，可直接导入Excel。

7. 非功能需求
================================================================================

- 性能：4000+只股票单次选股耗时 ≤5分钟（含缓存）。
- 可靠性：接口异常时自动降级（跳过不可用因子），关键数据缺失则报警退出。
- 扩展性：新增因子只需在配置中注册weight与对应计算函数，无需改动打分引擎。
- 合规说明：工具仅供个人学习研究，不构成投资建议。

8. 风险与应对
================================================================================

风险                        应对措施
----------------------------------------------------------------
免费接口积分不足            因子开关，自动重新分配权重；本地缓存减少调用
调用频率限制                请求间隔≥0.2s，全量缓存
财务数据滞后                输出时标明数据截止日期，日志提示“预估数据”
北向资金/主力资金不可用      直接关闭因子，使用量比、融资等替代
市场风格切换导致因子失效    提供回测功能定期复核因子IC，提醒用户调整权重
