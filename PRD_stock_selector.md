1. 项目概述
================================================================================

1.1 项目背景
基于A股市场，构建轻量级全自动选股工具，通过多因子打分模型筛选优质标的。
使用Tushare免费API，结果输出为CSV文件。

1.2 免费Token实测可用接口
接口             用途                       实测结果
----------------------------------------------------------------
bak_basic        日度基础数据(含财务指标)     可用，5470只
daily            日线行情(OHLCV)              可用，5458只/日
stock_company    上市公司基本信息             可用
stock_basic      股票列表                     不可用(5次/天限频)
trade_cal        交易日历                     不可用(无权限)
income           利润表                       不可用(需积分)
balancesheet     资产负债表                   不可用(需积分)
fina_indicator   财务指标                     不可用(需积分)
margin           融资融券                     不可用(需积分)
moneyflow        资金流向                     不可用(需积分)

1.3 核心结论
免费token实际只能稳定使用 bak_basic + daily 两个数据接口。所有因子必须
从这两个接口派生。bak_basic 单次调用即可获取全市场股票的价值、质量、成长、
规模等多维度数据，已足够支撑一套完整的选股模型。

2. 因子体系 (V2.0)
================================================================================

2.1 价值维度 (25%)
因子         权重    方向    来源              说明
----------------------------------------------------------------
ep_ttm       0.15    +       bak_basic.pe      1/PE，盈利收益率
bp           0.10    +       bak_basic.pb      1/PB，净资产折价

2.2 质量维度 (35%)
因子         权重    方向    来源              说明
----------------------------------------------------------------
roe_ttm      0.15    +       eps/bvps          股东回报率
gross_margin 0.10    +       bak_basic.gpr     毛利率=定价权
net_margin   0.10    +       bak_basic.npr     净利率=盈利质量

2.3 成长维度 (20%)
因子         权重    方向    来源              说明
----------------------------------------------------------------
revenue_yoy  0.10    +       bak_basic.rev_yoy     营收增速
profit_yoy   0.10    +       bak_basic.profit_yoy  利润增速

2.4 规模维度 (10%)
因子         权重    方向    来源              说明
----------------------------------------------------------------
small_cap    0.10    +       bak_basic.total_assets    -ln(总资产)，小盘溢价

2.5 技术维度 (10%)
因子         权重    方向    来源              说明
----------------------------------------------------------------
volume_ratio 0.10    +       daily(多日vol)    量比=vol/avg_vol_5d

3. 打分方法
================================================================================

- 每个因子在全市场内计算百分位排名(0~1)
- 负向因子取 1-rank 转为正向得分
- 加权得分：final_score = Σ(w_i × rank_i)
- 按总分降序取前N只股票（默认50）
- 当前版本为全市场排名，V2.1可增加行业内中性化

================================================================================
4. 股票池过滤
================================================================================

- 剔除 ST、*ST（从名称正则匹配）
- 剔除上市不足60天的股票（bak_basic.list_date）
- 剔除当日停牌/无交易的股票（daily覆盖）
- 仅保留沪深主板、创业板、科创板（从ts_code推导market）
